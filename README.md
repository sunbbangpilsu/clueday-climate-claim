# 청구리 — 경기 기후보험 '받을 권리' 청구 에이전트

자동가입된 경기 기후보험, **받을 권리까지** 챙겨주는 청구 도우미입니다.
이름은 보험금 **청구**와, 비 오기 전에 운다는 **청개구리**를 합쳤습니다. 날씨가 변하면 먼저 알려드려요.
진료 조건에 따른 예상 보장, 확인이 필요한 항목, 서류 체크리스트와 청구 준비 요약서를 제공합니다.
실제 접수에는 보험사 공식 청구서·동의서 작성과 증빙서류가 별도로 필요합니다.

## 현재 제공 범위 (v0.2)

- **실제 입력과 시연 분리:** 일반 모드에서는 샘플 특보로 지급액을 확정하지 않습니다. 특보가 필요한 항목은 `확인 대기`로 남깁니다. `?demo=1`은 가상 사례로 명확히 표시하며 개인 기록을 읽거나 저장하지 않습니다.
- **가족·진료 건 분리:** 본인/가족마다 여러 진료 건을 관리합니다. 질병코드, 결과, 서류 체크와 청구인·계좌 입력은 건별로 독립적입니다. 새 설치에는 가상의 가족이 자동 등록되지 않습니다.
- **입력 검증:** 일반 모드의 미래 진료일과 잘못된 코드 형식을 거부합니다. 가입 대상 여부, 기존 진단비 지급 여부, 감염병과 기후재해 조건을 입력할 수 있습니다.
- **진료 상황 카드:** 빈 입력에서 시작해 사용자가 직접 확인한 내용으로만 생성합니다. 날씨·증상·노출을 미리 채우지 않습니다.
- **청구 준비 요약서:** 공식 양식의 대체물이 아닙니다. 출력 문서에도 남은 접수 절차와 예상액 안내를 포함합니다.
- **개발 예정:** 기상청 실제 특보 연동, 사진 글자 인식(OCR), 자동 푸시 알림, 기관 대시보드. 현재 화면에 실제 작동하는 기능처럼 표시하지 않습니다.

## 바로 실행하기 (1분)

```bash
cd backend
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --port 8000
```

서버를 실행한 뒤, **같은 컴퓨터의 브라우저**에서 아래 주소를 여세요. (내 컴퓨터에서 실행한 서버라 다른 사람은 이 주소로 볼 수 없습니다.)

| 실행 후 열 주소 | 내용 |
|---|---|
| `http://localhost:8000/` | 화면 (모바일 웹) |
| `http://localhost:8000/?demo=1#result` | 가상 사례: 가입 대상·취약계층인 72세 어머니, 한랭질환 진단·응급실·입원 2일·통원 1회, 샘플 특보 가정. 합계 47만 원은 실제 지급 확정액이 아님 |
| `http://localhost:8000/docs` | API 문서 (Swagger) |

테스트: `backend` 폴더에서 `python -m pytest -q`

프로젝트 루트에서도 `python -m pytest -q`로 서버 회귀 테스트를 실행할 수 있습니다.
프론트엔드 상태 분리 테스트는 Node.js에서 `node --test tests/frontend-state.test.cjs`로 실행합니다.
Python 3.12에서 서버 테스트 33개, 프론트엔드 상태 테스트 7개를 검증했습니다.

프론트엔드만 따로 띄울 때는 `frontend` 폴더에서 `python -m http.server 5500` 실행 후 `http://localhost:5500` 을 여세요 (백엔드는 8000번 포트).

## 구성

| 폴더 | 내용 |
|---|---|
| `backend/` | FastAPI 서버. 보장표(`app/coverage.py`), 판정 규칙(`app/eligibility.py`), 기상특보(`app/alerts.py`, 1차는 샘플 데이터) |
| `frontend/` | 모바일 웹. 홈·진료 카드·보험금 확인·판정 결과·청구 준비 요약서·가족 화면 |
| `docs/` | 서비스 기획안, API 명세서, UI/UX 시안 (PDF·원본), `openapi.json` |
| `tools/build_docs.py` | 문서 Markdown → PDF 변환 |

## API 요약

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/health` | 서버 상태 |
| GET | `/api/coverages` | 2026 경기 기후보험 보장 항목 |
| GET | `/api/alerts?sigungu=부천시&on=2026-12-16` | 시군 기상특보 (1차: 샘플) |
| POST | `/api/eligibility` | 입력 조건 기준 예상 보장·확인 대기 항목·필요 서류·계산상 청구 기한 |
| POST | `/api/doctor-card` | 진료 전 상황 전달 카드 |
| GET | `/api/claim-channels` | 청구 접수 채널 |

자세한 내용은 [docs/API명세서.md](docs/API명세서.md)

`docs/openapi.json`과 위 Markdown 명세는 현재 구현 기준입니다. 기존 기획서·UI 시안·PDF/HTML은 최초 기획 스냅샷이므로 현재 기능 범위는 이 README와 API 명세를 기준으로 확인하세요.

## 개인정보·윤리 원칙

- 서버는 이름·주민번호·연락처·계좌·진단서 원본을 **받지 않고**, 판정 요청도 **저장하지 않습니다.**
- 이름·연락처·계좌·가족 정보와 진료 건별 입력은 이 브라우저의 로컬 저장소에 보관합니다. 판정 시 날짜·시군·질병코드·조건은 서버로 전송되지만 저장하지 않습니다.
- 진료 카드는 노출 상황을 전달하고 청구용 서류 발급을 요청할 뿐, **특정 질병코드를 요구하지 않습니다** (테스트로 검증).
- 판정은 예상치이며 최종 지급은 보험사 심사로 결정됩니다.

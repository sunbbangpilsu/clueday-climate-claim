# 청구리 API 명세서

경기 기후보험 '받을 권리' 청구 도우미의 백엔드 API입니다.

| 항목 | 내용 |
|---|---|
| Base URL (로컬) | `http://localhost:8000` |
| 형식 | JSON (UTF-8) |
| 인증 | 1차 버전 없음 (공개 정보·판정만 제공). 기관용 API는 2차에서 토큰 인증 추가 |
| 자동 문서 | `GET /docs` (Swagger UI), `GET /openapi.json` |
| 구현 | Python 3.14 · FastAPI · 자동 테스트 5개 (`backend/tests/test_api.py`) |

## 개인정보 원칙

- 서버는 **이름, 주민등록번호, 연락처, 계좌번호, 진단서 원본(사진)을 받지 않습니다.**
- 판정에 필요한 최소 정보(날짜, 시군, 질병코드, 체크 항목)만 받으며 **저장하지 않습니다.**
- 청구서에 들어가는 개인정보는 사용자 기기에서만 입력되고, 청구서는 기기에서 PDF로 저장됩니다.

## 엔드포인트 요약

| 메서드 | 경로 | 설명 | 상태 |
|---|---|---|---|
| GET | `/api/health` | 서버 상태 확인 | 동작 |
| GET | `/api/coverages` | 2026 경기 기후보험 보장 항목 목록 | 동작 |
| GET | `/api/alerts` | 시군의 기상특보 조회 | 동작 (샘플 데이터) |
| POST | `/api/eligibility` | 받을 수 있는 보험금·필요 서류·청구 기한 판정 | 동작 |
| POST | `/api/doctor-card` | 진료 때 의사에게 보여줄 상황 전달 카드 생성 | 동작 |
| GET | `/api/claim-channels` | 보험금 청구 접수 채널 안내 | 동작 |
| POST | `/api/org/cases` | (기관용) 취약계층 청구 진행 현황 등록 | 2차 예정 |
| GET | `/api/org/cases` | (기관용) 담당 대상자 청구 진행 현황 조회 | 2차 예정 |
| POST | `/api/push/subscribe` | 특보 푸시 알림 구독 (시군 단위, 익명) | 2차 예정 |

## 1. GET /api/health

서버 상태를 확인합니다.

**응답 200**
```json
{ "status": "ok", "service": "청구리", "version": "0.1.0" }
```

## 2. GET /api/coverages

2026 경기 기후보험(보험기간 2026.4.11 ~ 2027.4.10)의 보장 항목을 돌려줍니다. 출처: 경기도 기후보험 안내 (gg.go.kr/gg_insure)

| 쿼리 | 타입 | 필수 | 설명 |
|---|---|---|---|
| target | string | 아니오 | `all` = 도민 전체, `vulnerable` = 기후취약계층 특약 |

**응답 200 (일부)**
```json
{
  "policy_period": "2026-04-11 ~ 2027-04-10",
  "items": [
    { "id": "heat_diagnosis", "name": "온열질환 진단비", "target": "all", "amount": 150000,
      "condition": "온열질환(T67) 진단 (연 1회)", "codes": ["T67"], "docs": ["진단서 또는 소견서"] },
    { "id": "clinic_visit", "name": "의료기관 통원비", "target": "vulnerable", "amount": 20000,
      "condition": "기상특보 발령일에 진료 목적 방문 (1회당, 5회 한도)", "codes": [],
      "docs": ["진료확인서", "방문건강사업대상 확인서 또는 임산부확인서"] }
  ],
  "source": "https://www.gg.go.kr/gg_insure"
}
```

보장 항목 id: `heat_diagnosis` 온열질환 진단비 15만 원 · `cold_diagnosis` 한랭질환 진단비 15만 원 · `infection_diagnosis` 특정 감염병 진단비 20만 원 · `disaster_injury` 기후재해 사고 위로금 30만 원 · `death` 사망위로금 300만 원 · `er_visit` 응급실 내원비 10만 원 · `heat_hospital`/`cold_hospital` 입원일당 10만 원(취약계층, 5일 한도) · `clinic_visit` 통원비 2만 원(취약계층, 5회 한도)

## 3. GET /api/alerts

시군의 기상특보(폭염·한파 등)를 조회합니다. 통원비·기후재해 위로금은 **특보 발령일**이어야 보장되므로 판정에 쓰입니다.

| 쿼리 | 타입 | 필수 | 설명 |
|---|---|---|---|
| sigungu | string | 아니오 (기본 `부천시`) | 시군 이름 |
| on | date (YYYY-MM-DD) | 아니오 | 이 날짜에 발령 중인 특보만 |

**응답 200** — `GET /api/alerts?sigungu=부천시&on=2026-12-16`
```json
{ "sigungu": "부천시", "date": "2026-12-16",
  "alerts": [ { "sigungu": "부천시", "type": "한파주의보", "start": "2026-12-15", "end": "2026-12-18" } ],
  "source": "sample" }
```

> 1차 버전은 시연용 샘플 데이터(`source: "sample"`)입니다. 2차에서 기상청 특보 통보문 오픈API(기상자료개방포털·공공데이터포털)로 교체하며 응답 형식은 같습니다.

## 4. POST /api/eligibility

받을 수 있는 보험금, 항목별 근거, 필요한 서류, 청구 기한을 판정합니다. 규칙 기반이며 최종 지급 여부는 보험사 심사로 결정됩니다.

**요청 본문**

| 필드 | 타입 | 필수 | 설명 |
|---|---|---|---|
| event_date | date | 예 | 진료·사고 날짜 |
| sigungu | string | 아니오 (기본 `부천시`) | 사고 시군 (특보 확인용) |
| diagnosis_codes | string[] | 아니오 | 진단서·소견서의 질병코드 (예: `T67.0`) |
| infection | string | 아니오 | 감염병 이름 (뎅기열, 말라리아 등 10종) |
| er_visit | boolean | 아니오 | 응급실 진료 여부 |
| hospital_days | integer ≥ 0 | 아니오 | 입원 일수 |
| clinic_visits_on_alert_days | integer ≥ 0 | 아니오 | 특보 발령일 통원 횟수 (취약계층) |
| disaster_injury_weeks | integer ≥ 0 | 아니오 | 기후재해 사고 진단 주수 |
| death | boolean | 아니오 | 사망 여부 (유족 청구) |
| age | integer 0~130 | 아니오 | 나이 (미성년자 서류, 사망위로금 판정) |
| vulnerable | boolean | 아니오 | 기후취약계층 (방문건강관리사업 대상 또는 임산부) |

**요청 예시**
```json
{ "event_date": "2026-08-05", "sigungu": "부천시", "diagnosis_codes": ["T67.0"], "er_visit": true }
```

**응답 200**
```json
{
  "policy_year": "2026",
  "eligible": true,
  "total_amount": 250000,
  "items": [
    { "id": "heat_diagnosis", "name": "온열질환 진단비", "unit_amount": 150000, "count": 1, "amount": 150000,
      "reason": "진단서의 질병코드가 온열질환(T67)에 해당", "docs": ["진단서 또는 소견서"] },
    { "id": "er_visit", "name": "응급실 내원비", "unit_amount": 100000, "count": 1, "amount": 100000,
      "reason": "온열·한랭질환 또는 기후재해로 응급실 진료", "docs": ["응급실기록지", "진단서 또는 소견서"] }
  ],
  "required_docs": ["보험금 청구서", "개인정보처리동의서", "주민등록초본 (외국인: 국내거소신고사실증명서)",
                    "통장사본", "진단서 또는 소견서", "응급실기록지"],
  "alerts_on_event_date": [ { "sigungu": "부천시", "type": "폭염경보", "start": "2026-08-01", "end": "2026-08-12" } ],
  "claim_deadline": "2029-08-05",
  "deadline_passed": false,
  "notes": ["온열·한랭질환 진단비는 보험 기간 중 1회만 지급됩니다."],
  "disclaimer": "예상 판정입니다. 최종 지급 여부와 금액은 보험사(메리츠화재) 서류 심사로 결정됩니다."
}
```

**판정 규칙 요약**

| 조건 | 결과 |
|---|---|
| 사고일이 2026.4.11 ~ 2027.4.10 | 2026 약관 적용 |
| 사고일이 2025.4.11 ~ 2026.4.10 | 2025 약관 적용 (진단비 10만 원), 나머지는 보험사 확인 안내 |
| 질병코드 T67 | 온열질환 진단비 |
| 질병코드 T33·T34·T35·T68·T69 | 한랭질환 진단비 |
| 응급실 + (온열·한랭질환 또는 기후재해) | 응급실 내원비 |
| 특보 발령일 사고 + 4주 이상 진단 (취약계층 2주) | 기후재해 사고 위로금 |
| 취약계층 + 입원 | 입원일당 × 최대 5일 |
| 취약계층 + 특보 발령일 통원 | 통원비 × 최대 5회 |
| 사망 + 만 15세 이상 | 사망위로금 |
| 사고일 + 3년 | 청구 기한 |

**오류**: 필드 형식이 틀리면 `422 Unprocessable Entity` (FastAPI 검증 오류 형식)

## 5. POST /api/doctor-card

진료 때 의사에게 보여줄 카드 문구를 만듭니다. **노출 상황을 전달하고 청구용 서류 발급을 요청할 뿐, 특정 질병코드를 요청하지 않습니다** (자동 테스트로 검증).

| 필드 | 타입 | 필수 | 설명 |
|---|---|---|---|
| weather | `폭염` \| `한파` | 아니오 | 날씨 |
| exposure | string | 아니오 | 노출 상황 (예: 야외 작업) |
| hours | number 0~24 | 아니오 | 노출 시간 |
| symptoms | string[] | 아니오 | 증상 |
| alert_type | string | 아니오 | 당일 특보 (예: 한파주의보) |

**응답 200**
```json
{
  "title": "진료 전에 보여주세요",
  "lines": ["오늘 한파주의보 발령 중에 야외 작업을(를) 약 3시간 했습니다.", "증상: 오한·떨림"],
  "request": "경기 기후보험 청구를 위해, 진료 후 질병명과 질병분류코드가 기재된 진단서(또는 소견서) 발급을 부탁드립니다.",
  "notice": "이 카드는 노출 상황을 전달하기 위한 것입니다. 진단은 의사의 판단이며 특정 질병코드를 요청하지 않습니다."
}
```

## 6. GET /api/claim-channels

보험금 청구 접수 채널을 안내합니다 (경기도 공식 안내 기준).

**응답 200 (일부)**
```json
{
  "insurer": "메리츠화재 (경기도 계약 보험사)",
  "channels": [ { "type": "카카오톡", "how": "카카오톡에서 '경기 기후보험' 채널 친구추가 → 보상청구하기 → 서류 사진 업로드" } ],
  "call_center": "02-2078-4548",
  "payout": "서류 심사 후 3일 이내 지급"
}
```

## 2차 개발 예정 (최종 제출 전)

| 기능 | 내용 |
|---|---|
| 실제 특보 연동 | `/api/alerts`를 기상청 특보 오픈API로 교체, 시군 단위 캐시 |
| 특보 푸시 | `/api/push/subscribe`: 시군만 받는 익명 구독 (Web Push) |
| 기관용 대시보드 | `/api/org/cases`: 보건소·방문건강관리 담당자가 대상자 청구 진행 단계만 관리 (진단 내용·서류 원본은 저장하지 않음), 기관 토큰 인증 |
| 기기 내 글자 인식 | 진단서 사진에서 질병코드를 휴대폰 안에서 추출 (서버 전송 없음) |
